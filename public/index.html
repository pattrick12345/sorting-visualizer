Why this site exists

Sorting algorithms are easy to read about and hard to picture. A block of code doesn't show you how the numbers move around. This site turns each algorithm into bars you can watch, so you can see every comparison and swap as it happens.

Each page pairs the animation with plain-English steps and live counts of comparisons and swaps, so you can see why some algorithms take far more work than others as the array grows.
